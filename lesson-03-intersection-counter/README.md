# Урок 3: Навигация и подсчет перекрестков

Робот уже умеет следовать по линии благодаря ПД-регулятору. Сегодня необходимо научить робота определять перекрестки (когда оба датчика видят черную линию), считать их количество и выполнять задания — например, останавливаться на 5-м перекрестке.

## 🔌 Схема подключения
Схема остается точно такой же, как на прошлом уроке. Датчики линии подключены к пинам `A0` и `A1`.

## 🧠 Логика определения перекрестка
Как понять, что робот находится на перекрестке? И левый, и правый датчики должны одновременно зафиксировать черный цвет. Для этого задана константа `THRESHOLD` (порог). Если значение на датчике меньше этого порога — под ним черная линия.

Казалось бы, достаточно написать: `if (видим_перекресток) { счетчик = счетчик + 1; }`. Но при программировании микроконтроллера возникают нюансы, связанные со временем выполнения цикла `loop()`. В функции `crossRoad()` пропущены важные элементы логики, которые необходимо исправить.

### 1. Сохранение значения счетчика
Функция `crossRoad()` вызывается сотни раз в секунду. Действительно ли переменная счетчика `count` объявлена правильно, и будут ли ее значения отличны от 0 или 1 при последующих вызовах?
**Задача:** Изменить объявление переменной `count` так, чтобы она не стиралась при выходе из функции. Обратите внимание на модификатор переменной `wasCross` строчкой выше.

### 2. Многократное срабатывание
Ширина черной линии составляет несколько сантиметров. Робот проезжает ее за долю секунды, но цикл `loop()` за это время успеет выполниться сотни раз. Если оставить условие как есть, счетчик будет постоянно увеличиваться, пока датчики находятся над линией.
**Задача:** Исправить условие `if`. Счетчик должен увеличиваться на 1 только в момент заезда на перекресток — то есть, когда сейчас робот находится на перекрестке (`isCross`), а в предыдущей итерации цикла его там еще не было (`!wasCross`).

### 3. Обновление состояния
Чтобы логика из предыдущего пункта работала корректно, программе необходимо помнить свое прошлое состояние при следующем вызове функции.
**Задача:** Дописать строку кода перед выходом из функции (`return`), которая сохранит текущее состояние (`isCross`) в переменную прошлого состояния (`wasCross`).

## 💻 Задание
1. Настройте константу `THRESHOLD`. Воспользуйтесь функцией `sensors()` из прошлого урока, чтобы определить значения датчиков на черной линии. Впишите нужное пороговое число.
2. Перенесите в функцию `followLine()` оптимальные коэффициенты `kp` и `kd`, подобранные ранее.
3. Проанализируйте функцию `crossRoad()` и исправьте описанные выше логические ошибки.
4. Внутри блока `loop()` напишите алгоритм: робот должен ехать по линии (`followLine()`), пока счетчик перекрестков меньше 5. Как только счетчик достигнет 5, робот должен остановиться.

> 💡 **Совет:** Чтобы остановить робота окончательно, недостаточно просто вызвать функцию `motors(0, 0);`. На следующей итерации `loop()` программа продолжится. Используйте пустой бесконечный цикл `while (true) {}` сразу после команды остановки моторов.
